# Wetter

Private, nicht-kommerzielle Wetter-App (PWA) für Handy und PC: Messwerte, Radar mit 2-Stunden-Vorhersage, Satellit, Modellkarten, Wind, Warnungen, Favoriten, PV-Prognose pro kWp, Luftqualität.

**App:** https://markuscode75.github.io/wetter/mobile/

Daten: Deutscher Wetterdienst (CC BY 4.0), Open-Meteo.com, Copernicus CAMS, EUMETSAT, OpenStreetMap/OpenTopoMap. Details und Lizenzen: [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Eigener Code: [MIT](LICENSE). Alle Angaben ohne Gewähr.
